# Project role

Composition Studio is the forward-looking target system. It should consolidate only proven ideas from the other active repositories instead of copying their full historical architecture.

Current reference roles:
- Music Chat Lab: dialogue and workflow reference
- Minimal Composer: minimal composition architecture / experiment reference
- Composition Lab Native: macOS, notation, MusicXML, MIDI I/O and CLAB reference

This repository should remain lean. Experimental throwaway patches and migration helpers should not accumulate here; once a change is consolidated, the active source should contain the result directly.
