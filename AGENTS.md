# Anweisungen für Composition-Studio

Vor jedem Entwicklungsauftrag [zentrale KI-Entwicklungsstandards](https://github.com/wibem1/AI-Development-Standards/blob/main/DEVELOPMENT_STANDARDS.md) lesen. Anschließend `PROJECT_STATE.md`, vorhandene README/TODO/Issues und den betroffenen Code auswerten. Bestehende fachliche/technische Regeln bleiben gültig. Nur überschaubare Aufgaben, geeignete Funktionstests, keine unbelegten Freigaben, keine unnötigen Builds/API-Kosten. Relevante Fortschritte mit Nachweisen in `PROJECT_STATE.md` sichern.
